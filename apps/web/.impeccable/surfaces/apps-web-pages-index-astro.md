# Marketing home

Mode: Persuade. Audience: consultant/implementer and agent power user; developer-with-own-API is a quieter third. Job: believe the same-day loop (server → tool → playground → agent URL) and Sign up. Proof: the gate cut, then the session — one agent builds the MCP in conversation, another agent puts it to work, five lines of config between them. Constraints: brand manual (Ink, Paper, Gate Orange, Inter, system mono, custom wordmark); no invented testimonials, metrics, customers, or shipped-roadmap; hero composition stays as approved; no magazine serif/photo; no AI mascot/glow/glass. User relaxations 2026-09-14: scroll-driven motion is allowed below the hero when it carries the story; Gate Orange may act as a functional accent beyond the 2 (handshake URL, live pulse, selected chip). Approved hero comp: `.impeccable/mocks/decision/gate-cut.webp`. Approved below-fold comp: `.impeccable/mocks/session-wire.png` (wire topology × acts choreography).

## Direction contract

THESIS: After the gate, the page performs the product instead of describing it. One agent authors a tool through conversation (the platform-MCP door); another agent puts that tool to work (the gateway door); the handshake between them — a five-line config slip — is the emotional proof. It refuses the feature-card stack, equal marketing bands, and the text-ledger cull that replaced them.

OWN-WORLD: Paper `#FFFFFF` ground, Ink `#0B0B0B` type, Gate Orange `#FD410B` as functional accent only: the handshake URL, the live pulse, the selected picker chip. Inter for chrome; system mono for endpoints, curl, protocol frames, URLs, verdicts, tokens. Sharp rectangles, hairline rules, no glow, glass, or drop shadow. The word `healthy` stays Ink, not green.

STORY: The visitor picks an orphan endpoint, then scrolls three acts: ACT 1 BUILD — a conversation turns the curl into `void_invoice` and the playground answers `healthy`; ACT 2 HANDSHAKE — the config slip crosses the gutter from the builder window to the worker window; ACT 3 WORK — the billing specialist calls the tool and finishes the job. Then a compressed ledger (shipped today / stays closed / not yet / who passes / FAQ) and Sign up.

FIRST VIEWPORT: Unchanged — the approved gate-cut hero. Wordmark lockup and Sign up / Log in at the end of that scroll.

FORM: Session stage — wire topology (BUILD and WORK windows flanking the handshake slip on the gutter, picker strip above, ledger below) choreographed as three scroll-paced acts; stacks to a single-column act order on narrow viewports. No seed: shaped directly from the user's approved combination of comps `session-wire.png` + `session-acts.png`, orange accent from `session-handshake.png`.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
